About this site

{{site_name}} is a scaffold for a dynamic multi-page site on the PULSE Beacon core. It uses xiom.template 0.2.0 for layouts, loops, conditionals and auto-escaping, and PULSE's urlencoded parser for HTML forms.

The static tree under public/ is served through the Beacon fallback hook with the same traversal guard and validators as the Station site mode. Registered routes always take precedence over the fallback.

This is an example, not the product server. A production site should cache the template strings at startup and put a TLS-terminating proxy in front of PULSE.
